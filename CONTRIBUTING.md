# Contributing to Flight Deck Simulator

Thanks for your interest in improving the simulator.

## Getting started

1. Fork the repository.
2. Clone your fork locally.
3. Open `index.html` in a browser or run `npm start` after installing dependencies.

## Recommended improvements

- Add additional instrument gauges.
- Improve the flight dynamics and stall handling.
- Add sound effects and a cockpit panel.
- Support mobile touch controls.

## Reporting issues

Please open an issue if you find bugs or want to propose enhancements.
